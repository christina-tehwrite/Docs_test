# Реки России

Реки играют важную роль в природе и хозяйстве России. Они обеспечивают регионы водой, служат транспортными путями и формируют разнообразные природные ландшафты.

В этом разделе собраны краткие статьи о нескольких известных реках России:

- [Свирь](svir.md)
- [Нева](neva.md)
- [Ангара](angara.md)

Каждая из этих рек интересна своим положением, историей и значением для окружающих территорий.
