# Ангара

Ангара — крупная река Восточной Сибири и единственная река, вытекающая из озера Байкал. Она имеет большое значение для природы и экономики региона.

Река известна своими мощными водными ресурсами. На Ангаре построены крупные гидроэлектростанции, которые обеспечивают электроэнергией многие территории Сибири.

Ангара также важна как природный объект. Ее течение, берега и связь с Байкалом делают реку значимой частью сибирского ландшафта.
