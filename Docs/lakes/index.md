# Озера России

Россия богата озерами самых разных размеров и происхождения. Среди них есть как небольшие водоемы, так и огромные озерные системы, известные во всем мире.

В этом разделе собрана краткая информация о нескольких известных озерах России:

- [Онежское озеро](onega.md)
- [Ладожское озеро](ladoga.md)
- [Байкал](baikal.md)

Каждое из этих озер имеет свои особенности, природную ценность и важное значение для регионов, в которых находится.
