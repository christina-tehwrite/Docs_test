# Онежское озеро

Онежское озеро — одно из крупнейших озер России. Оно находится на северо-западе страны и занимает важное место в природной системе Карелии и соседних регионов.

Озеро известно своими живописными берегами, островами и богатой историей. На одном из островов расположен музей-заповедник Кижи, который считается важным памятником русской деревянной архитектуры.

Онежское озеро используется для судоходства, рыболовства и туризма. Его природные ландшафты привлекают путешественников в любое время года.
